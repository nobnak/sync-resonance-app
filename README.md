# SynchroEcho (ホタルの同期・カエルの反同期)

> **自然界の振動子が紡ぐ「引き込み」と「排他」の音響数理アート**  
> ホタルの同相同期（引力 $K > 0$）によるカタルシスと、カエルの逆相排他（斥力 $K < 0$）によるポリリズムを視覚的・聴覚的に体験できる Web アプリケーションです。

---

## 🌟 特徴

- **ゼロ・ディペンデンシー（Pure HTML5 / CSS3 / ES6 JavaScript）**  
  外部ライブラリを一切使わず、ブラウザ標準の **Web Audio API** と **HTML5 Canvas 2D** のみで実装されているため、軽量・超高速で、GitHub Pages にそのまま配置するだけで動作します。
- **音楽的な必然性を持った音響設計**  
  単なる無味乾燥なビープ音ではなく、散乱時・過渡期・秩序期のすべてにおいて音楽的な美しさが成立するよう調律しています。
  - **ホタル（引力）**：ペンタトニック／リディアン調の温かいベル・ローズ音色。散乱時は淡いアンビエント和音、完全同期時は一撃の壮大なユニゾンコード（フォルテッシモ）に収斂。
  - **カエル（斥力）**：水滴・ウッドブロック・マリンバ調のパーカッション。反同期によって音が衝突せず、緻密なインターロッキング・ポリリズム（ガムランのコトカン的輪唱）を形成。
- **空間オーディオ（Spatial Panning）**  
  各個体の画面上の $X$ 座標がステレオ定位（パンニング）に連動し、音が空間を巡る感覚を知覚できます。
- **リアルタイム・インタラクション**  
  - **結合強度 $K$ の連続変化**：斥力（-1.5）〜 カオス（0）〜 引力（+1.5）をシームレスに行き来可能。
  - **外乱（摂動）の注入**：画面をクリックすると水面の波紋のように衝撃波が広がり、位相が乱れて再び秩序へ向かう「緊張と弛緩」のサイクルを観察できます。
  - **個体のドラッグ**：個体を掴んで移動させ、局所的なクラスタリングや音響配置を変えることができます。

## 🚀 GitHub Pages への公開手順（3ステップ）

このプロジェクトは完全な静的 Web サイトです。以下の手順ですぐに公開できます。

### 1. GitHub 上で新しいリポジトリを作成
GitHub（github.com）で任意の名前（例: `sync-resonance-app`）のリポジトリを新規作成します。

### 2. ローカルからプッシュ
```bash
git init
git add .
git commit -m "feat: initial commit of SynchroEcho"
git branch -M main
git remote add origin https://github.com/<あなたのユーザー名>/<リポジトリ名>.git
git push -u origin main
```

### 3. GitHub Pages を有効化
1. リポジトリの **Settings**（設定）タブを開きます。
2. 左メニューの **Pages** を選択します。
3. **Build and deployment** の Source で **Deploy from a branch** を選択し、Branch を **`main` / `/(root)`** に設定して **Save** を押します。
4. 数分待つと、`https://<あなたのユーザー名>.github.io/<リポジトリ名>/` で世界中に公開されます！

## 🔬 数理モデル

本システムは、距離依存の空間カーネルを持つ**蔵本モデル（Kuramoto Model）**をベースにしています。

$$\frac{d\theta_i}{dt} = \omega_i + \frac{K}{N} \sum_{j \neq i} W(d_{ij}) \sin(\theta_j - \theta_i)$$

- $\theta_i$ : 第 $i$ 個体の位相 ($[0, 2\pi)$)
- $\omega_i$ : 固有角速度（個体ごとの微妙な速度差・ゆらぎ）
- $K$ : 結合強度
  - **$K > 0$（ホタル）**：相手の位相へ引き寄せられる（同相引込み $\Delta\theta \to 0$）
  - **$K < 0$（カエル）**：相手の位相から離れようとする（逆相排他・位相分散）
- $W(d_{ij})$ : 空間距離減衰カーネル $\frac{1}{1 + (d_{ij} / R)^2}$
- **秩序度 $r$（Order Parameter）** :
  $$r e^{i\psi} = \frac{1}{N} \sum_{j=1}^N e^{i\theta_j}$$
  ホタルの同期時は $r \to 1.0$、カエルの反同期時（位相が均等分散）は $r \to 0.0$ となります。
