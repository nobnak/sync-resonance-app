# SynchroEcho (ホタルの同期・カエルの反同期)

> **自然界の振動子が紡ぐ「引き込み」と「排他」の音響数理アート**  
> ホタルの同相同期（引力 $K > 0$）によるカタルシスと、カエルの逆相排他（斥力 $K < 0$）によるポリリズムを視覚的・聴覚的に体験できる Web アプリケーションです。

🎮 **Web アプリを体験する（ブラウザでそのまま動作します）**  
👉 **[https://nobnak.github.io/sync-resonance-app/](https://nobnak.github.io/sync-resonance-app/)**

## 🌟 特徴

- **ゼロ・ディペンデンシー（Pure HTML5 / CSS3 / ES6 JavaScript）**  
  外部ライブラリを一切使わず、ブラウザ標準の **Web Audio API** と **HTML5 Canvas 2D** のみで実装されているため、軽量・超高速で、GitHub Pages で軽快に動作します。
- **適応型 2D 格子配置（Adaptive Grid Layout）**  
  画面のアスペクト比に合わせて中央に整列する 2 次元格子上に発振子を配置。近傍同士の局所相互作用がドミノ倒しのように伝播する波面や、チェッカーボード模様の千鳥発火を直感的に視認できます。
- **音楽的な必然性を持った音響設計**  
  単なるビープ音ではなく、散乱時・過渡期・秩序期のすべてにおいて音楽的な美しさが成立するよう調律しています。
  - **ホタル（引力）**：ペンタトニック調の温かいベル・ローズ音色。散乱時は淡いアンビエント和音、完全同期時は一撃の壮大な斉唱コード（フォルテッシモ）に収斂。
  - **カエル（斥力）**：短打アタックのウッドブロック・パーカッション。反同期によって発音タイミングが自然に分散し、緻密なインターロッキング・ポリリズム（ガムラン調の千鳥輪唱）を形成。
- **空間オーディオ（Spatial Panning）**  
  各個体の画面上の $X$ 座標がステレオ定位（パンニング）に連動し、音が格子空間を巡る感覚を知覚できます。
- **多彩なパラメータ操作と時間伸縮不変性**  
  - **結合強度 ($K$)**：斥力（-1.5）〜 カオス（0）〜 引力（+1.5）をシームレスに行き来可能。
  - **個体数 ($N$)**：$2 \sim 100$ 匹（$2\times2$ 〜 $10\times10$ の最適な格子構成に自動吸着）。
  - **テンポ速度**：ダイナミクスの秩序構造を変えずに純粋な再生速度（スロー〜高速）を伸縮可能。
  - **周期のばらつき（$\pm 0\% \sim \pm 30\%$）**：各個体の個性（固有角速度）の散らばり幅を調整。
  - **生体ゆらぎ・ノイズ（$0\% \sim 20\%$）**：毎フレームのランダムな微小撹乱。
  - **結合範囲（半径）**：格子間隔の $1.0\times$（直近傍のみ）〜 $6.0\times$（広域結合）まで相互作用の届く範囲を任意に制御。
- **ワンクリックで体験できるプリセット**  
  - ✨ **ホタルの群生 (36匹)**：6×6格子の引力結合。カオスから壮大な斉唱コードへの収斂。
  - 🌌 **百景・大同期 (100匹)**：10×10格子。全体をうねる光と音の波面伝播。
  - 🐸 **カエル大合唱 (36匹)**：局所斥力結合。チェッカーボード状の千鳥発火と重層ポリリズム。
  - 🐸 **カエル輪唱 (4匹)**：2×2格子。対角ペアが交互に鳴き交わすミニマル・ポリリズム。
  - ⏱️ **フェージング (Reich 9点)**：スティーヴ・ライヒに因む微弱結合。微妙な速度差によるミニマル音楽的フェーズシフト。
  - 🌀 **カオス群生 (64点)**：結合なし ($K=0$)。それぞれが独立して鳴り続ける無秩序なアンビエント。
- **リアルタイム・インタラクション**  
  - **画面タップ / 突風ボタン**：位相を乱して再び秩序へ向かう「緊張と弛緩」の遷移を観察。
  - **格子点の直接タップ**：任意の格子点を刺激し、波紋状に位相変化が伝播する様子を触覚的に操作。

## 🔬 数理モデル

本システムは、距離依存の空間カーネルを持つ**蔵本モデル（Kuramoto Model）**をベースにしています。

$$\frac{d\theta_i}{dt} = \left( \omega_i + K \cdot c \cdot \frac{\sum_{j \neq i} W(d_{ij}) \sin(\theta_j - \theta_i)}{\sum_{j \neq i} W(d_{ij})} \right) \cdot v_{\text{speed}} + \eta_i(t)$$

- $\theta_i$ : 第 $i$ 格子点の位相 ($[0, 2\pi)$)
- $\omega_i$ : 固有角速度（基本角速度 $\omega_0$ にばらつき率を加味した個体固有のペース）
- $K$ : 結合強度
  - **$K > 0$（ホタル）**：同相引込み（$\Delta\theta \to 0$）
  - **$K < 0$（カエル）**：逆相排他（$\Delta\theta \to \pi$、位相分散）
- $W(d_{ij})$ : コーシー／ローレンツ型の空間距離重み $\frac{1}{1 + (d_{ij} / R)^2}$（$R = \text{格子間隔} \times \text{結合半径倍率}$）
- $v_{\text{speed}}$ : テンポ倍率（時間軸の均等伸縮）
- $\eta_i(t)$ : ガウシアン風の生体ランダムゆらぎ（ノイズ項）
- **蔵本秩序度 $r$（Order Parameter）** :
  $$r e^{i\psi} = \frac{1}{N} \sum_{j=1}^N e^{i\theta_j}$$
  ホタルの完全同期時は $r \to 1.0$、カエルの反同期やカオス時（位相が均等分散）は $r \to 0.0$ となります。
