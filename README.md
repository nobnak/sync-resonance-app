# SynchroEcho (ホタルの同期・カエルの反同期)

> **自然界の振動子が紡ぐ「引き込み」と「排他」の音響数理アート**  
> ホタルの同相同期（引力結合 $K > 0$）によるカタルシスと、カエルの逆相排他（斥力結合 $K < 0$）によるポリリズムを視覚的・聴覚的に体験できる Web アプリケーションです。

## 🌟 特徴

- **ゼロ・ディペンデンシー（Pure HTML5 / CSS3 / ES6 JavaScript）**  
  外部ライブラリや npm パッケージを一切使用せず、ブラウザ標準の **Web Audio API** と **HTML5 Canvas 2D** のみで実装。軽量・超高速で、GitHub Pages で軽快に動作します。
- **適応型 2D 格子配置（Adaptive Grid Layout）**  
  画面のアスペクト比に合わせて中央に整列する 2 次元正方格子上に発振子を配置。近傍同士の局所相互作用がドミノ倒しのように伝播する波面や、チェッカーボード模様の千鳥発火を視覚的・幾何学的に明瞭に観察できます。
- **大気の波（空間相関ゆらぎ）による「生命感の呼吸」**  
  標準的な蔵本モデルでは同期すると全位相差が完全固定（$r = 1.00$ や静止平衡）してしまいますが、本アプリでは森や湿原を渡る風を模した**「大気の波（2D 空間相関低周波ゆらぎ）」**を導入。大数の法則による打ち消しを打破し、同期状態でも秩序度が $75\% \sim 95\%$ の間を有機的に呼吸するようにうねり続けます。
- **音楽的な必然性を持った音響設計**  
  単なる無機質なビープ音ではなく、散乱時・過渡期・秩序期のすべてにおいて音楽的な美しさが成立するよう調律しています。
  - **ホタル（引力結合）**：温かみのあるベル／エレクトリックピアノ調の倍音豊かなサイン波合成。各個体にペンタトニック／モーダル音階を分散配置。散乱時は淡いアンビエント和音、同期時は豊かな斉唱コード（フォルテッシモ）に収斂します。
  - **カエル（斥力結合）**：マリンバ／ウッドブロック／水滴調の鋭いアタックを持つパーカッション。反同期によって発音タイミングが自然に分散し、緻密なインターロッキング・ポリリズム（ガムラン調の千鳥輪唱）を形成します。
- **空間オーディオ（Spatial Panning）**  
  各個体の画面上の $X$ 座標がステレオ定位（パンニング）に連動し、音が格子空間を巡る感覚を知覚できます。
- **多彩なパラメータ操作と時間伸縮不変性**  
  - **結合強度 ($K$)**：斥力（-1.5）〜 カオス（0）〜 引力（+1.5）をシームレスに行き来可能。
  - **個体数 ($N$)**：$2 \sim 100$ 匹（$2\times2$ 〜 $10\times10$ の最適な格子構成に自動吸着）。
  - **テンポ速度**：ダイナミクスの秩序構造を変えずに純粋な再生速度（スロー〜高速）を伸縮可能。
  - **周期のばらつき（$\pm 0\% \sim \pm 30\%$）**：各個体の個性（固有角速度）の散らばり幅を調整。
  - **生体ゆらぎ・ノイズ（$0\% \sim 20\%$）**：大気の波の振幅および個体ごとの微細な確率拡散を制御。
  - **結合範囲（半径）**：格子間隔の $1.0\times$（直近傍のみ）〜 $6.0\times$（広域全結合）まで相互作用の届く範囲を任意に制御。
- **ワンクリックで体験できるプリセット（レスポンシブ・グリッド配置）**  
  - ✨ **ホタルの群生 (36匹)**：6×6格子の引力結合。大気の風を受けて秩序度 75%〜95% を呼吸するようにうねる斉唱。
  - 🌌 **百景・大同期 (100匹)**：10×10格子。大気の波によって光と音のさざ波が格子内を巡る壮大な波面伝播。
  - 🐸 **カエル大合唱 (36匹)**：局所斥力結合（半径 $1.2\times$）。チェッカーボード状の千鳥発火と重層ポリリズム。
  - 🐸 **カエル輪唱 (4匹)**：2×2格子。対角ペアが交互に鳴き交わすミニマル・ポリリズム。
  - ⏱️ **フェージング (Reich 9点)**：スティーヴ・ライヒに因む微弱結合。微妙な速度差によるミニマル音楽的フェーズシフト。
  - 🌀 **カオス群生 (64点)**：結合なし ($K=0$)。それぞれが独立して鳴り続ける無秩序なアンビエント。
- **リアルタイム・インタラクション**  
  - **格子点の直接タップ**：任意の格子点を刺激し、波紋状に位相変化と発音が伝播する様子を触覚的に操作。
  - **画面タップ / 突風ボタン**：衝撃波を起こして位相をかき乱し、再び秩序へ向かう過渡応答を観察。

## 🔬 数理モデル

本システムは、空間距離重みカーネルおよび大気ゆらぎ項を拡張した**蔵本モデル（Kuramoto Model）**をベースにしています。

### 1. 位相発展方程式

各格子点 $i$ の位相 $\theta_i \in [0, 2\pi)$ は以下の微分方程式に従って発展します：

$$\frac{d\theta_i}{dt} = \left( \omega_i^{\text{eff}}(\mathbf{x}_i, t) + K \cdot c \cdot \frac{\sum_{j \neq i} W(d_{ij}) \sin(\theta_j - \theta_i)}{\sum_{j \neq i} W(d_{ij})} \right) \cdot v_{\text{speed}}$$

- $\mathbf{x}_i = (x_i, y_i)$ : 第 $i$ 格子点の空間座標
- $K$ : 結合強度（$K > 0$：同相引込み $\Delta\theta \to 0$、$K < 0$：逆相排他 $\Delta\theta \to \pi$）
- $c = 1.6$ : 結合感度係数
- $v_{\text{speed}}$ : テンポ倍率（時間軸の均等伸縮・不変性）
- $W(d_{ij})$ : コーシー／ローレンツ型の空間距離重み
  $$W(d_{ij}) = \frac{1}{1 + \left( \frac{d_{ij}}{R_{\text{eff}}} \right)^2}, \quad R_{\text{eff}} = \text{cellSpacing} \times \text{radiusMultiplier}$$

### 2. 大気の波（空間相関低周波ゆらぎ）

各個体の実効固有角速度 $\omega_i^{\text{eff}}$ は、固定固有角速度 $\omega_i$ に大気の波 $W_{\text{breeze}}$ が乗算されて動的に変調されます：

$$\omega_i^{\text{eff}}(\mathbf{x}_i, t) = \omega_i \cdot \left( 1 + W_{\text{breeze}}(\mathbf{x}_i, t) \right)$$

$$\omega_i = \omega_0 \cdot (1 + \text{freqNorm}_i \cdot \text{freqSpread})$$

$$W_{\text{breeze}}(\mathbf{x}_i, t) = \sigma_{\text{wind}} \cdot \left[ 0.55 \sin(0.45 t + 0.005 x_i + 0.003 y_i) + 0.45 \cos(0.32 t - 0.004 x_i + 0.006 y_i) \right]$$

ここで $\sigma_{\text{wind}} = \text{noiseLevel} \times 4.2$ です。この空間相関波により、大数効果によるノイズの相殺が防がれ、定常状態でも秩序度が滑らかに呼吸します。

### 3. 位相の確率積分（Euler-Maruyama）

各時間ステップ $\Delta t$ において、微小な生体ノイズ（Brownian increment）を加えて位相を進めます：

$$\theta_i(t + \Delta t) = \theta_i(t) + \left( \frac{d\theta_i}{dt} \right) \Delta t + \sigma_{\text{micro}} \cdot \xi_i \sqrt{\Delta t} \cdot v_{\text{speed}}$$

- $\xi_i \sim \text{Uniform}(-0.5, 0.5)$
- $\sigma_{\text{micro}} = \text{noiseLevel} \times 2.0$

### 4. 蔵本秩序度 (Kuramoto Order Parameter)

系全体のコヒーレンス（集団的同期度）は複素秩序パラメータの絶対値 $r \in [0, 1]$ で評価されます：

$$r e^{i\psi} = \frac{1}{N} \sum_{j=1}^N e^{i\theta_j}$$

- **$r \to 1.0$**：完全同期（ホタルが完全に同一位相で発光）
- **$r \approx 0.75 \sim 0.95$**：大気の波に乗り、生命感を持って有機的に呼吸する同期群生
- **$r \to 0.0$**：完全反同期（カエルが均等に位相分散して千鳥発火）または完全無秩序（カオス）
